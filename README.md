# site-crm

CRM-аналитика сети школ бокса (5 филиалов) и магазина спорттоваров.

## Структура
- `index.html` — сайт (страница выбора филиала и страницы филиалов, маршрутизация через `#/…`)
- `css/app.css` — стили (mobile-first)
- `js/` — логика: `config.js` (разделы, пороги), `store.js` (данные), `views/` (страницы)
- `data/seed.json` — демо-данные филиалов, задач и показателей
- `design/` — визуальные варианты макетов (выбраны 1A и 2A)

## Запуск локально
```sh
python3 -m http.server 8000
# открыть http://localhost:8000
```
Двойным кликом по index.html сайт не откроется: модулям и загрузке данных нужен локальный сервер.

## Данные
Пока данные хранятся в браузере (localStorage) поверх `data/seed.json`.
Кнопка «Данные» на главной позволяет выгрузить и загрузить JSON.

## Деплой
GitHub Pages через Actions (`.github/workflows/pages.yml`), при каждом пуше в `main`.

## Иконки
[Solar Icons](https://www.figma.com/community/file/1166831539721848736) от 480 Design, лицензия CC BY 4.0. Нужные иконки встроены локально в `js/icons.js` (скачаны через Iconify).

## Библиотеки
- [ApexCharts](https://apexcharts.com) 3.45.2 (MIT) — графики, лежит локально в `vendor/apexcharts/`.
